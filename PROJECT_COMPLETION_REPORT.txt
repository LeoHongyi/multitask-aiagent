🔧 系统架构

用户输入
    ↓
[FastAPI] 接收请求
    ↓
[MultiTaskAgent] 处理查询
    ├─ [LLM] 任务分类 (有降级)
    ├─ [LLM] 生成工具调用 (有降级)
    ├─ [并发] 执行多个工具 (ToolManager)
    └─ [LLM] 生成回复 (有降级)
    ↓
[Redis] 保存会话 (可选)
    ↓
返回结构化结果

  • 月度成本: ~30 USD (1000查询/天)

  ✓ GET    /api/tools                   - 工具列表
  ✓ POST   /api/cache/clear             - 清空缓存
  ✓ GET    /health                      - 健康检查
  ✓ GET    /                            - API 信息

🤖 支持的工具

WeatherTool
  功能: 城市天气查询
  参数: city (城市名称)
  返回: 温度、天气、湿度
  延迟: ~500ms

NewsTool
  功能: 科技新闻获取
  参数: category, limit
  返回: 新闻列表、来源、日期
  延迟: ~800ms

SearchTool
  功能: 网络搜索
  参数: query (搜索关键词)
  返回: 搜索结果、链接、摘要
  延迟: ~600ms

TextProcessTool
  功能: 文本处理
  参数: text, action (summarize/uppercase/lowercase/word_count)
  返回: 处理后的文本
  延迟: 同步

🎓 使用示例

Python 异步调用:
  from core.agent import MultiTaskAgent
  agent = MultiTaskAgent(tool_manager)
  result = await agent.process_query("北京天气")

cURL 调用:
  curl -X POST http://localhost:8000/api/chat \
    -H "Content-Type: application/json" \
    -d '{"query":"北京天气"}'

JavaScript 客户端:
  const response = await fetch('http://localhost:8000/api/chat', {
    method: 'POST',
    body: JSON.stringify({query: '北京天气'})
  });
